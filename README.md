# Cutroom Mac downloads

Public packaged-app downloads only. Cutroom source development stays private.

The current Apple Silicon test release is 1.0.4-rc.2 (macOS arm64, ZIP). It uses ad hoc integrity signing and is not Apple Developer ID signed or notarized. The owner tested a browser download and normal macOS Privacy & Security approval successfully. Install manually; automatic unsigned installation is unavailable. Intel Mac builds are not offered here.
